## Ses

- ElevenLabs `eleven_v4`, ses: hesaptaki "YouTube Shorts" (Türkçe erkek belgesel anlatıcı), `language_code: tr`.
- Sayılar yalnızca TTS için yazıyla okutuldu ("Bin dokuz yüz yirmilerde", "on ikinci"...); `words.json` metnin yazımını koruyor.
- Kelime saatleri API'nin karakter hizalamasından (Whisper'a gerek kalmadan, birebir).
- Ham ses 69,1 sn (1,88 kelime/sn) → boşluklar kısaltıldı (cümle sonu .22, virgül .14, cümle içi .09 sn) → ×1,3 `atempo` → **49,2 sn, 2,64 kelime/sn**.
- Müzik ve efektler hikâyeye özel `audio/mix.py`: Re minör müzik kutusu + kalp atışı; 1928 kesmesinden sonra müzik kutusu susar, dron kararır.

Yeniden üretmek için (anahtar yalnızca ortam değişkeninden okunur):

```bash
ELEVENLABS_API_KEY=... python stories/bogdanov/tools/tts.py /tmp/tts 1.0
python stories/bogdanov/tools/kes_esle.py /tmp/tts/raw.wav /tmp/tts/raw_words.json stories/bogdanov/voice/voice.wav stories/bogdanov/voice/words.json 1.3
python tools/zarf.py stories/bogdanov/voice/voice.wav stories/bogdanov/voice/env.json
cd engine && node render.mjs bogdanov --cues && cd .. && python stories/bogdanov/audio/mix.py stories/bogdanov
cd engine && node render.mjs bogdanov
```
