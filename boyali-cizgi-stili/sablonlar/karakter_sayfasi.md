# Karakter tasarım formu

Her yeni karakter için bu formu doldurun, sonra `promptlar.md` → `[KARAKTER]` bloğuna aktarın. Değerler referanstan ölçüldü (`STIL_KITABI.md` §3).

| Alan | Kural | Sizin karakteriniz |
|---|---|---|
| Kavram (tek cümle) | Kendine güvenen ama beceriksiz bir arayıcı/avcı/hırsız tipi iyi çalışır. Arzusu, onu felakete sürükler | |
| Ten rengi | L 15-25, kroma ≤ 12; mor-siyah, erik, kahve-mor. Örn. #362a38, gölge #1a111c, ışık #443442 | |
| Göz | İki büyük beyaz disk (#faf4eb), yüz genişliğinin ~%45'i; iğne ucu siyah bebek; kalın koyu kapak kenarı | |
| Ağız | İnce çizgi ↔ geniş beyaz dişli sırıtma ↔ büyük oval panik (#23030c) | |
| Siluet | Uzun ince boyun, ince uzuvlar, iri eldivenli eller (4 parmak), sivri uçlu ayaklar | |
| Baş aksesuarı | Yuvarlak kask/şapka, 2 renk (örn. koyu teal + pembe benek) | |
| Kostüm renkleri (4-5) | Paletten: teal #185a62, krem #e4e0b2, hardal #e4bd59, deri #572d2e, pas #9c4c37, mor-gri #7b697c, koyu gri #2a2c2c | |
| Sıcak vurgu | Yanak/kulak #ac594f ya da kask beneği #d6837d (küçük alan) | |
| Hikâye nesnesi | Sahnenin tek doygun vurgusu olabilir (örn. turuncu #d57906) | |
| 6 ifade | nötr · sinsi yarım kapak sırıtma · iri göz şok · endişe · panik açık ağız · kibirli | |

## Kontrol
- [ ] Teal gök önünde siluet net mi (karakter koyu, gök açık)?
- [ ] Gözler kadrajın en parlak noktası mı?
- [ ] Kostüm teali gökten belirgin şekilde koyu mu (L ~35'e karşı ~68)?
- [ ] Hiçbir yerde siyah kontur var mı? (olmamalı)
- [ ] Referanstaki karakterden **farklı mı**? (farklı siluet, farklı kask/şapka, farklı kostüm düzeni)

## Yaşayan dünya öğeleri (rakip / engel)
Çalı, meyve, kaya, kaktüs gibi şeyler "canlı" olabilir. Kurallar:
- Paletten renk alın (hardal çalı, turuncu meyve, pembe-kırmızı kaya).
- Ağız içi koyu bordo-kırmızı (#23030c – #7b2b19), dişler küçük yuvarlak boncuklar ya da diken.
- Canlanmadan önce sıradan bir sahne nesnesi gibi görünmeli (ters köşe ancak böyle işler).
